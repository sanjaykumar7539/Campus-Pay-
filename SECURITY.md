# Security Policy

## Supported Versions
Only the active development versions receive security updates.

## Reporting a Vulnerability
We take the security of CampusPay seriously. If you find a security vulnerability, please do not open a public issue. Instead, report it directly to our security team.

Please email your report to: **security@campuspay.example.com**

Please include:
- A detailed description of the vulnerability.
- Steps to reproduce or a proof of concept.
- Potential impact of the vulnerability.

We will acknowledge your report within 48 hours and provide a timeline for resolution.
