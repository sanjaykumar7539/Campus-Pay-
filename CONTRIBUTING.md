# Contributing to CampusPay

Thank you for your interest in contributing to CampusPay! We welcome contributions from the community.

## Code of Conduct
Please read and adhere to our [Code of Conduct](CODE_OF_CONDUCT.md).

## Getting Started
1. Fork the repository and create your branch from `main`.
2. Install dependencies for the specific service you are working on.
3. Ensure your changes adhere to our [Coding Standards](docs/CODING_STANDARDS.md).
4. Run existing tests before submitting a pull request.

## Pull Request Process
- Update the [Changelog](CHANGELOG.md) with any significant changes.
- Ensure the pull request template is fully completed.
- Your changes must pass all CI checks (linting, testing, building) before merge.
